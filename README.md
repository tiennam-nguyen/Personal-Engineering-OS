# PEOS

Personal Engineering OS is a local-first, single-user, offline-capable modular monolith.

This repository currently contains only Milestone 0: the repository constitution. It has no
production CLI, artifact storage, database, model provider, or workflow behavior.

Start with [MAP.md](MAP.md), [PLAN.md](PLAN.md), and the ADRs in [adr](adr). Development and
verification commands are in [CONTRIBUTING.md](CONTRIBUTING.md).

## Scope boundary

Milestone 1 begins the artifact round trip. Do not treat this scaffold as a workspace
implementation.
